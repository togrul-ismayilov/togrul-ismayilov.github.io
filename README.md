# ISVA Games website

Served by GitHub Pages at https://togrul-ismayilov.github.io/.

- `maze-defense/privacy/`: the privacy policy of Maze Defense (`com.isvagames.mazedefense`), linked from the game's Settings, its Play listing, and its AdMob consent message. Keep this address stable: it is built into the game.
- `maze-defense/terms/`: the terms of service of Maze Defense, the link Google Play asks of a trader for each app. Keep this address stable too: Play Console names it.
- `app-ads.txt`: the AdMob seller line, read by AdMob's crawler at the site's root.
- `index.html`: the home page.
